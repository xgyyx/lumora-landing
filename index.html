PHILOSOPHY

映微入幽，
让影像之光洞穿病理

「朗」者清朗通透，「曜」者日月星辰之光。
我们相信，每一张影像都是给疾病显形的一束光—— 让小型诊所也能拥有专业的影像托管基础设施， 让每一个疑难病例都能触达资深判读的洞察。

在朗曜，影像不再散落于 U 盘和网盘；判读不再依赖微信群和邮件附件。
从上传到归档，从浏览到判读——一条完整、稳定、专业的闭环。

PRODUCT ARCHITECTURE

双主线，一站式

影像基础设施与专家判读服务并行，互为流量与价值的双向通道。

主线一

云 PACS

影像基础设施 · 订阅日常使用

  • ▪ 替代 U 盘、网盘的散落式管理，影像云端集中托管
  • ▪ 按宠物、检查日期、模态浏览，历史病例随时回看
  • ▪ 浏览器内 2D 阅片，调窗、测量、Cine 播放即开即用
  • ▪ 长期保留，影像永不丢失

主线二

远程判读

专家服务 · 按单付费

  • ▪ 资深兽医教授判读，专业中文诊断报告
  • ▪ 结构化报告：所见 · 印象 · 建议三段式
  • ▪ 核心片高亮，关键证据自动嵌入报告
  • ▪ 在线查看 + PDF 下载，宠主端可分享

◇ 两条主线共用同一账号、同一影像库、同一权限基线。订阅 PACS 客户可从影像直接发起判读订单；单次付费客户体验后可随时升级，历史影像自动并入影像库。

CORE CAPABILITIES

核心特性

从上传到判读，从浏览到归档——每一处都为兽医诊所的真实场景打磨。

全功能 Web 上传器

拖拽整个文件夹，自动识别 DICOM；断点续传，进度可见；按 Study / Series 自动归类，无需手动整理。

浏览器内 2D 阅片

调窗预设（肺窗 / 骨窗 / 软组织）、缩放平移、距离角度测量、多帧 Cine 播放——无需安装任何客户端。

MPR 三视图重建

专家工作台原生支持轴位 / 冠状位 / 矢状位三视图联动，CT 与 MRI 的细节定位一气呵成。

结构化诊断报告

按部位 × 模态预设模板，「所见 / 印象 / 建议」三段式填空，核心片自动嵌入，PDF 一键导出。

影像长期保留

所有客户的 DICOM 影像长期归档，即便单次付费也不丢失；订阅 PACS 时历史影像自动并入影像库。

一键发起判读

日常浏览遇到疑难病例，从 Study 一键发起判读订单——影像无需再上传，专家自动接收。
